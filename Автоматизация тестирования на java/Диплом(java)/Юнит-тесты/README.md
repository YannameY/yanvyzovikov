# Диплом: Юнит-тестирование

## 🧪 Описание проекта

Дипломное задание по модульному тестированию на Java. Проект демонстрирует применение принципов DI, мокирования зависимостей, параметризованных тестов и анализа покрытия кода.

---

## 📚 Технологии

### 🌐 Ядро проекта

| Технология | Версия  |
|------------|---------|
| Java       | 11      |
| Maven      | 3.9.0   |

### 🧪 Тестирование

| Библиотека | Версия  | Назначение                                         |
|------------|---------|----------------------------------------------------|
| JUnit 4    | 4.13.2  | Фреймворк для модульного тестирования              |
| Mockito    | 4.8.0   | Библиотека для создания мок-объектов               |
| AssertJ    | 3.21.0  | Fluent-assertions для удобных проверок             |
| JaCoCo     | 0.8.10  | Анализ покрытия кода тестами                       |

---

## ⚙️ Настройка

### Предварительные требования

- Установите JDK 11 ([скачать](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html))
- Установите Maven 3.9.0 ([инструкция](https://maven.apache.org/install.html))

### Запуск тестов

```bash
mvn clean test
```

### Генерация отчёта покрытия

```bash
mvn jacoco:report
```

Откройте файл `target/site/jacoco/index.html` для просмотра отчёта.

---

## 🎯 Подход к тестированию

- 📌 Каждый метод каждого класса вызывается в отдельном тесте
- 📌 Для каждой ветки условия написан отдельный тест
- 📌 Для некоторых веток используются параметризованные тесты

> ⚠️ Проект состоит из **обязательного** и **дополнительного** заданий. Дополнительное задание не влияет на оценку, но поможет получить больше опыта.

## ✅ Обязательное задание

### Пошаговый план

- [ ] Привяжи GitHub к тренажёру. Репозиторий `qa_java` появится автоматически с заготовкой проекта
- [ ] Собери Maven-проект: подключи JaCoCo, Mockito и JUnit
- [ ] Класс `Lion` не должен зависеть от класса `Feline`. Используй принцип инъекции зависимостей (DI)
- [ ] Напиши моки с помощью Mockito
- [ ] Напиши тесты на классы `Feline`, `Cat` и `Lion`
- [ ] Реализуй параметризованные тесты
- [ ] Обеспечь покрытие **не менее 100%** для классов `Feline`, `Cat` и `Lion` через JaCoCo

### Критерии оценки

- ✅ Нейминг элементов корректный
- ✅ В `pom.xml` подключены JaCoCo, Mockito и JUnit
- ✅ В `pom.xml` нет ничего лишнего
- ✅ Тесты лежат в `src/test/java`
- ✅ Класс `Lion` не зависит от класса `Feline`. Код написан с инъекцией зависимости
- ✅ В тестах используются моки
- ✅ В тестах используется параметризация
- ✅ Классы `Feline`, `Cat` и `Lion` покрыты тестами на 100%
- ✅ Параметризованные тесты вынесены в отдельный класс
- ✅ Сделан отчёт с помощью JaCoCo. Отчёт закоммичен
- ✅ В проекте используется Java 11

## 🌟 Дополнительное задание (Optional)

### 🦁 Создание класса льва Алекса

Класс льва Алекса из мультфильма «Мадагаскар». Наследник класса `Lion`.

#### Собственные методы

| Метод                | Описание                                                                 |
|----------------------|--------------------------------------------------------------------------|
| `getFriends()`       | Возвращает список имён друзей — зебра Марти, бегемотиха Глория, жираф Мелман |
| `getPlaceOfLiving()` | Возвращает место проживания — Нью-Йоркский зоопарк                      |

#### Переопределение и конструктор

- Переопределён метод `getKittens()` (у Алекса нет львят)
- Свой конструктор (в `Lion` нет дефолтного; Алекс — самец)
- Класс покрыт тестами

### Критерии оценки

- ✅ Написан класс лев Алекс
- ✅ Класс лев Алекс покрыт тестами

## 📤 Отправка отчёта JaCoCo в Git

```bash
# Добавляем папку с отчётом JaCoCo (ключ -f, если target в .gitignore)
git add -f ./target/site/jacoco/.

# Выполняем коммит
git commit -m "add jacoco report"

# Отправляем в удалённый репозиторий
git push
```
